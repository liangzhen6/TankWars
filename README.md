# TANK WARS · 坦克大战（三关 Web 版 + Switch 测试包）

一个可以直接在浏览器里玩的 8-bit 风格坦克大战，并额外加入了一套原创“超能力 / 武侠”技能系统。现在包含三关战役，支持 **1–2 人同屏合作**，并附带一个可安装到 Switch（大气层）的 NX.js `.nro` 测试包。界面按 Switch 横屏构图组织：正方形战场撑满屏幕高度，标题与实时状态在左栏，技能与瞄准提示在右栏。像素画面、UI、地图和音效全部由代码绘制 / 合成，不依赖 ROM、外部图片或音频素材。

三关是一段很短的一生：**初生（CRADLE）** 的老鹰被石头完全护住，可以自由探索；**中坚（HOMESTEAD）** 只剩一圈土墙，要自己守住家；**落幕（DUSK）** 没有任何保护，任何一炮都可能结束它。第三关结束不会进入普通失败界面，而是进入一段关于“给自己留一点时间”的结局彩蛋。

当前版本为 **0.2.5**，完整变更见 [`CHANGELOG.md`](CHANGELOG.md)。双人同屏已完成；Switch 端支持两个独立手柄。

## 立即开始

不需要安装任何依赖，也不需要构建：

- 直接双击 `index.html`（Chrome / Edge / Firefox / Safari 均可）。
- 或在本目录启动一个本地服务器：

```bash
python3 -m http.server 4173
```

然后打开 <http://127.0.0.1:4173>。

## 操作

网页端默认 1P，标题页按 `1` / `2` 选择人数，再按 `Enter` 或点击画面开始。

| 操作 | P1 | P2 |
| --- | --- | --- |
| 移动 | `WASD` | 方向键 |
| 开火 | `Space` / `J` | `Enter` / `Numpad0` |
| 磁力场 | `Q` / `1` | `7` |
| 心念支配 | `E` / `2` | `8` |
| 瞬移 | `F` / `3` | `9` |
| 瞄准时移动光标 | 自己的移动键 / 鼠标 | 自己的移动键 |
| 确认瞄准 | `Space` / `Enter` / 点击 | `Enter` / `Space` / 点击 |
| 取消瞄准 | `Esc` / 再次点击当前技能卡 | `Esc` / 再次点击当前技能卡 |
| 暂停 / 继续 | `P` / `Esc` | 任一玩家 |
| 静音 | `M` | 任一玩家 |
| 重新开始 | `R` | 任一玩家 |
| 开始 / 重开一局 | `Enter`，或点击画面 | — |

> 菜单里 `Enter` 是确认；进入游戏后 `Enter` 是 P2 开火键。手机 / 平板的触屏控制器目前只驱动 P1。

## 双人同屏

- **经典双人规则**：P1 / P2 各自拥有生命、分数、火力和复活；不共享生命池。P2 使用青色坦克。
- **独立技能**：每人拥有自己的磁力场、心念支配和瞬移冷却与技能卡；右侧同时显示 P1 / P2 两套技能。
- **同一时间只能有一个人进入战术瞄准**；瞄准期间敌军坦克和敌方炮弹降到 12% 速度，但另一名玩家的坦克保持全速、可以继续移动和开火。瞄准者本人原地静止。
- **得分归属**：玩家自己的炮弹记给本人；策反友军的炮弹记给策反者。
- **前两关**：两人都阵亡才 GAME OVER；一人倒下时另一人继续。倒下的玩家在本关内不会复活，下一关保留 0 命状态。
- **第三关**：每人获得 1 条最终生命（即使前两关有人耗尽）。两人都倒下，或老鹰被任何一炮击毁（含 60 秒命运坦克），都会进入结局彩蛋。
- **Switch**：人数在标题页用十字键 / 摇杆左右选择，不再根据手柄数量自动判断。选 2P 就会出现两辆坦克；第二个手柄连接后直接控制 P2（十字键 + A + X/Y/R，与 P1 相同的按键布局），中途接上也生效。

## 这一版包含

- **三关原创战役**：CRADLE（10 台）、HOMESTEAD（14 台）、DUSK（敌军无限），每关布局、钢墙/河流/树林结构和敌军编成不同。
- 关卡推进：分数与生命跨关保留，前两关清空敌军后进入下一关；第三关没有“清空敌军”出口，最终由老鹰的存亡或 1 分钟期限接管。
- **第三关没有任何保护**：老鹰裸露在底部，敌方炮弹、流弹和你自己的炮弹都能一炮击毁它。老鹰被毁后不显示 GAME OVER，而是直接进入结局彩蛋。
- **第三关的 1 分钟保底**：如果玩家很强，一直守住老鹰，第 60 秒一台“命运坦克”会在老鹰正上方的空格里显形，炮口朝下开一炮，然后进入彩蛋。
- **第三关的提前结束**：这一关每人只有一条命。老鹰被任何一炮击毁，或两人都阵亡，都会直接进入彩蛋，不必等到 1 分钟。
- 4 种敌军坦克：普通、快速、火力、装甲。敌方会寻路、追击、攻击基地，也会随机游走和打砖开路。
- 出生点防卡死：玩家或策反友军占住出生点时自动改选其他出生点；三点全被占超过约 2.4 秒，会把占点坦克轻推到附近空位（玩家短暂护盾），然后继续刷怪。
- 每名玩家默认 3 条命、出生护盾、基地防守、子弹对撞、爆炸粒子、屏幕震动；第三关每人都只有最后 1 条命。
- 分数与生命按玩家分别跨关保留（火力进入新关会重置），进入第三关时每人的生命收束为 1 条。
- 每关会在固定的击毁节点掉落火力星：提升射速、弹速与同屏弹数；坦克被击毁或进入新关后火力重置。
- 三套主动技能，灵感来自“操控金属 / 控制心灵 / 空间跃迁”的超能力与武侠母题，但名称、视觉和数值都是原创；**每名玩家各自拥有独立冷却和技能卡**：
  - **磁力场（P1 Q/1 · P2 7）**：张开磁场，吸收进入范围的敌方炮弹，并把附近坦克向玩家牵引，暂时封住它们的火炮。
  - **心念支配（P1 E/2 · P2 8）**：先进入瞄准，自由选择任意一台敌军，确认后把它彻底策反成紫色友军。友军会自主寻路、追击并攻击其他敌军；它的击杀记给策反者。
  - **瞬移（P1 F/3 · P2 9）**：先进入瞄准，在最大 176 像素范围内自由选择落点，可以穿越砖墙、钢墙和河流；落地后获得约 1 秒护盾，并留下残影。
- **战术瞄准模式**：选择心念支配或瞬移后进入瞄准。单人模式下整个战场降为 12% 速度；双人模式下**只有敌方坦克和敌方炮弹降为 12%**，另一名玩家的坦克保持全速。同一时间只能有一人瞄准，瞄准最长 7 秒；确认后技能才进入冷却，取消不会消耗技能。
- 瞄准时可用自己的移动键或鼠标移动光标；`Space` / `Enter` / 点击确认，`Esc` 或再次点击当前技能卡取消。
- 策反会立刻减少“剩余敌军”计数，因此前两关的目标是**击毁或策反当前关全部敌军**（10 / 14 台）。第三关敌军无限，左侧 ENEMY 会显示 `∞`；这一关的目标不是清场，而是活到最后一刻。心念支配没有可用目标时不会进入瞄准。
- 技能卡会显示 `READY / 冷却秒数 / LIVE / AIM / WAIT`；双人时左右两侧各有一套 P1 / P2 技能卡。
- **双人 HUD**：左侧同时显示 P1 / P2 的分数、生命和火力；右侧显示两套技能面板。1P 时 P2 面板自动隐藏。
- **Switch 横向界面布局**：中间正方形战场撑满屏幕高度，标题与实时状态在左栏，技能卡与瞄准提示在右栏；网页预览采用 16:9 机身比例。双人时左右栏分别显示 P1 / P2 状态和两套技能。
- 本地最高分取两人中的较高分（`localStorage`）；标题 / 关卡开场 / 暂停 / 失败界面，以及第三关专属的结局彩蛋。
- 分层合成音效：玩家/敌军炮弹出膛、子弹对撞、砖墙碎裂、钢墙跳弹、护盾吸收、坦克爆炸、友军损失、基地/中枢大爆破、道具出现与拾取、敌军出生、开场与结算。
- 手机竖屏自动切换为“战场 + 技能 + 状态”的堆叠布局，触屏控制固定在底部；横屏手机使用紧凑侧栏。

## 三关：一生

| 关卡 | 主题 | 老鹰 | 玩法 |
| --- | --- | --- | --- |
| 01 · CRADLE | 初生 | 被一圈钢墙完全封死 | 自由探索、游玩；老鹰不会被击毁，只需清空 10 台敌军 |
| 02 · HOMESTEAD | 中坚 | 只有一圈砖墙 | 责任与担当；守住只剩一层土的家，清空 14 台敌军 |
| 03 · DUSK | 落幕 | 完全裸露，没有任何保护 | 敌军无限、每人 1 条命；老鹰任何一炮都能击毁，1 分钟是保底期限 |

第三关的三个结局入口：

1. **老鹰被击毁**：敌方炮弹、流弹、甚至玩家自己的炮弹，任何一炮都能击毁老鹰，短暂爆炸后进入彩蛋。
2. **两人都阵亡**：第三关每人只有 1 条命；一人倒下时另一人继续，两人都倒下后短暂爆炸并进入彩蛋，不显示 GAME OVER。
3. **活到 1 分钟**：如果玩家很强，一直没让任何炮弹碰到老鹰，战场边缘会逐渐变暗。第 60 秒，一台骨白色的“命运坦克”会在老鹰正上方显形，炮口朝下，瞄准老鹰只开一炮。老鹰爆炸后直接进入彩蛋。

三条路都不会出现普通的失败结算，因为第三关的“失败”本身就是通关。

## 结局彩蛋

彩蛋在网页端是一整屏的 DOM 覆盖层，Switch 端使用同一套内容画在 416 × 416 战场 Canvas 上并放大到 720p。画面包含：

- 坦克大战风格的暗色战场背景、透视网格地面、缓慢飘落的彩纸（撒花）。
- 三张关卡回顾卡：初生 / 中坚 / 落幕，每张有对应的像素老鹰图标、一行英文小标签和一句很短的中文注释。
- 最后的话：有一天，我们终会长大，变成一个无聊且忙碌的大人，慢慢老去，慢慢死去。但无论多忙，都要留一点点时间给自己，做自己喜欢的事情。
- “哪怕只是，再打一局曾经的坦克大战。”以及“再玩一次”按钮（`Enter` 或点击）。

网页端预览彩蛋：`index.html?ending=1`。预览第三关命运坦克：`index.html?stage=3&finale=1&ft=2.2`（`ft` 是剧情秒数，约 0–5.3）。

## 实现与优化

- **零依赖**：单个 `game.js` + Canvas 2D。Canvas 现在只绘制 416 × 416 的战场，2× 背板渲染；标题、状态和技能卡由左右两栏 DOM 承载，外框按 Switch 的 16:9 比例组织，战场在中间占满全高。
- **60Hz 定步循环**：逻辑用 accumulator 固定 1/60 秒推进，渲染每帧一次；高刷新率屏幕不会改变移动速度，卡顿后也不会「快进」。
- **静态层烘焙**：地形、树林分别烘焙到离屏 Canvas，只有砖块被击毁时才重建；水面做轻量程序化动画。
- **导航网格缓存**：BFS 使用 13 × 13 粗网格，地图变化时只失效一次缓存；敌人寻路目标包含基地、玩家和随机游走点。
- **AI 节奏**：开局以游走为主，随着关卡时间推进提高压基地概率；打穿基地外墙后进入短暂「压制冷却」，避免一梭子直接终结。
- **碰撞**：坦克 AABB + 16px 半格地图；子弹按 4px 子步推进，避免高速穿透；砖块按半格破坏。
- **技能系统**：每名玩家各自持有 `skills` 和 `targeting`；冷却、持续时间、范围和 UI 状态分离。单人瞄准时世界降到 12% 速度；双人瞄准时敌军与敌方炮弹降到 12%，瞄准玩家原地静止，另一名玩家保持全速继续战斗。心念支配会改变敌军阵营、渲染配色和 AI，并处理友军子弹归属与敌方仇恨。
- **双人架构**：`players[]` 分别保存位置、生命、分数、火力、技能、瞄准和复活计时；子弹带 `credit` 记录得分归属；敌人追击随机存活玩家；HUD 与 Switch 侧栏都按玩家分别渲染。第三关以“两人都倒下 / 老鹰被击毁 / 60 秒命运坦克”作为团队结束条件。
- **Switch 复用层**：`game.js` 原样运行在 NX.js 的 OffscreenCanvas 上，通过一个浏览器 DOM shim 提供状态/按钮/事件接口；Switch 主程序把战场和原生 Canvas 侧栏合成到 1280 × 720，并把两个 gamepad 分别映射为 P1 / P2 的移动、开火和技能。NX.js 缺少 oscillator / biquad / compressor，音频自动切换为 JavaScript 生成的 AudioBuffer 路径。

## 开发调试

打开 `index.html?debug=1` 会暴露 `window.__tankWars`，可读取对局快照、跳转玩家位置、跳到任意关卡、直接跳到第三关命运坦克的某一秒，或提前进入彩蛋，方便做浏览器自动化和手感测试。正常游玩时不需要它。

常用的无头预览参数：

```text
index.html?stage=1&time=2            直接进入第一关
index.html?players=2&stage=1&time=2  直接进入双人第一关
index.html?stage=3&time=50           第三关，距离命运坦克还有 10 秒
index.html?stage=3&finale=1&ft=2.2   第三关命运坦克，剧情第 2.2 秒（瞄准）
index.html?ending=1                  直接预览结局彩蛋
```

## Switch 测试包

已生成自包含的 fat NRO：

```text
switch/tank-wars.nro   （约 54 MB，NX.js 1.0.0-beta.7 runtime 已内嵌）
```

安装：

1. 把 `tank-wars.nro` 复制到 SD 卡 `/switch/tank-wars.nro`。
2. 在大气层 hbmenu 中启动 **TANK WARS**。
3. **必须从应用模式启动**：在主页选中任意游戏，按住 `R` 再按 `A` 打开 hbmenu，然后启动 NRO。相册 applet 模式只有约 380 MiB，当前 720p 画面会 OOM 闪退。

Switch 手柄（两人同屏时每个手柄控制一名玩家）：

| 输入 | 功能 |
| --- | --- |
| 手柄 1（P1） | 十字键 / 左摇杆移动，A 开火 / 确认，B 取消，X / Y / R 三技能 |
| 手柄 2（P2） | 与手柄 1 相同布局，控制青色坦克 |
| + / - / L | 暂停 / 重新开始 / 静音（任一手柄） |

人数在标题页用十字键 / 摇杆左右选择（1 或 2），不再根据手柄数量自动切换：选 2P 后就出现两辆坦克，第二个手柄接上即控制 P2，中途连接也生效。网页端不支持手柄，双人使用键盘。

重新构建：`cd switch && ./build.sh`。不需要 devkitPro，`@nx.js/nro` 自带打包所需 runtime。详细说明见 [`switch/README.md`](switch/README.md)。

> 当前 NRO 为 **0.2.5**：包含三关新剧本、第三关“命运坦克”结局、最后的彩蛋，以及**双人同屏**（每人独立生命 / 分数 / 火力 / 技能，两个手柄各控制一名玩家）。0.2.1 恢复了双人瞄准时敌军 12% 减速（只慢敌方，不慢队友），并把 Switch 人数选择改为标题页手动选择；0.2.2 为 Switch 音频加入自动重试与诊断日志；0.2.3 汉化 Switch 界面（HUD 英文标签、任务/说明/关卡界面/彩蛋中文，与网页一致）；0.2.4 将 Switch 中文改为内嵌点阵字形（实机自定义字体方案会卡死）。Switch 端彩蛋使用战场 Canvas 绘制，文案与网页 DOM 版一致；A 键在彩蛋界面可以再玩一次。此前的 0.1.7 修复了 NX.js 上两个主要的 native 内存增长源——带数字字重的 `ctx.font` 会重复注册系统字体（改为 `normal` 字重 + 缓存），以及每个音效都新建 AudioBuffer/节点（改为 96 个缓冲的缓存 + `onended` 断开）；修复了玩家/策反友军占住敌军出生点导致刷怪卡死的问题；Switch 上关闭了会看起来像“地图刷新”的屏幕抖动；音频改为启动时初始化、运行时查找 AudioContext、提高 master 音量并加入诊断日志。实机若仍无声，请查看 `/switch/nxjs-debug.log` 里的 `[audio]` 行。
